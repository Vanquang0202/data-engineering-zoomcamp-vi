# Từ API đến Data Warehouse: Data Ingestion với dlt có AI hỗ trợ

[Video](https://www.youtube.com/watch?v=5eMytPBgmVs)

Workshop thực hành này tập trung vào việc xây dựng các pipeline Data Ingestion đáng tin cậy để đưa dữ liệu vào Data Warehouse (chẳng hạn Snowflake) bằng dlt (data load tool), kết hợp LLM, dlt dashboard và dlt MCP.

## Bạn sẽ học được gì

Bạn sẽ thực hành những thành phần chính của một hệ thống Data Ingestion sẵn sàng vận hành thực tế, gồm:

- Trích xuất dữ liệu từ API, file và cơ sở dữ liệu
- Chuẩn hóa dữ liệu theo schema nhất quán
- Ghi dữ liệu vào Data Warehouse (ví dụ: Snowflake)
- Dùng LLM để đẩy nhanh quá trình phát triển pipeline dlt
- Kiểm tra dữ liệu và các thay đổi schema bằng dlt dashboard và dlt MCP

Buổi học tập trung hoàn toàn vào thực hành và viết code. Sau workshop, bạn sẽ hiểu cách thiết kế pipeline Data Ingestion dễ bảo trì, có khả năng mở rộng, đồng thời biết dùng AI và các công cụ kiểm tra để xây dựng pipeline nhanh hơn, tự tin hơn.
